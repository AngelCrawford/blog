The overview tile for a Rubrik, Tag or Serie — cover, name, count, nothing else.

```jsx
<TermCard title="Allgemein" href="/rubriken/allgemein/" cover="assets/images/covers/rubriken-cover.jpg" count={14} />
```

Centred title, 230px cover in sepia that releases on hover. The count deliberately excludes withered entries, so the number on the tile matches what the page then lists.
