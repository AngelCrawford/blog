One-line status note — form validation, build feedback, "Eintrag gespeichert".

```jsx
<Message tone="warning">Dieser Eintrag ist verwelkt.</Message>
```

A 4px left edge in the state colour on `--color-surface`, text in the same colour. Three tones only: success, warning, error. For the full withered notice on an article use `WitheredBanner` instead.
