{{- /* Garden — link render hook, ported from article-time. External links get the security attributes, the site's favicon via DuckDuckGo's proxy, and a screen-reader note. THE FAVICON STAYS AN INLINE STYLE. It contains the target's hostname, and a class name with a variable in it is a class Tailwind never generates (rule 6 in CLAUDE.md) — this is per-link data, not design. `sr-only` is the utility article-time's own helper class imitated. */ -}} {{- $link := .Destination -}} {{- $isExternal := or (strings.HasPrefix $link "http") (strings.HasPrefix $link "//") -}} {{- $hostname := "" -}} {{- if $isExternal -}}{{- $hostname = (urls.Parse $link).Host -}}{{- end -}} {{- .Text | safeHTML -}} {{- if $isExternal }} (öffnet in neuem Tab){{ end -}}
