Flächen und Tiefe

Drei Ebenen, und die Regel dazu: eine Ebene sitzt nur auf einer anderen Ebene. Panel auf Seite, Karte auf Panel oder Seite — nie Panel auf Panel. Genau diese Einschränkung macht Tiefe auf so dunklem Grund lesbar, weil Schatten hier kaum wirken.

{{- /* Ordered as a depth ladder, deepest first. The top box carries NO background of its own so the page shows through, dots and all — an earlier version filled it, which hid the very thing it was meant to demonstrate and left only a border to look at. */ -}}
Seitengrund Keine eigene Fläche — das Punktraster der Seite scheint durch. Alles andere liest sich gegen diesen Grund.
gd-panel-plain Gleiche Ebene, nur gerahmt. Gruppiert Zusammengehöriges, ohne eine neue Tiefenstufe zu verbrauchen.
gd-panel Eine Stufe höher: hellere Füllung, Rahmen, Schatten. Für Fließtext und Bedienelemente.

Wie ein Blog überlebt

Ein Absatz Fließtext, damit die Überschrift etwas hat, wogegen sie sich behaupten muss. Die Zeilenlänge ist auf lesbare Breite begrenzt, weil ein Text über die volle Fensterbreite nach zwei Zeilen anstrengend wird.

Der erste Abschnitt

Die goldene Linie führt das Auge nach rechts und trennt den Abschnitt vom Vorhergehenden, ohne einen harten Strich zu ziehen.

Ein Unterpunkt

Gold und kleiner: klar untergeordnet, aber noch als Überschrift lesbar. Darunter folgt gewöhnlicher Text mit einem Link und etwas hervorgehobenem Text.
